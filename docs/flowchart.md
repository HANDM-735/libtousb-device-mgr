# libtousb-device-mgr 项目流程图

## 1. 项目概述
这是一个C++库，用于通过USB接口管理软件定义无线电(SDR)系统中的各种板卡设备。

## 2. 整体架构

```
+-------------------------------------------------------------+
|                    Client Application                        |
|                   (main.cpp 测试程序)                        |
+----------------------------+--------------------------------+
                             |
                             v
+-------------------------------------------------------------+
|                    Lib USB Device Mgr                        |
|                  (libusb/lib_interface.h)                    |
|  +-------------+  +-------------+  +---------------------+  |
|  | USB Init    |  | OTA Upgrade |  | Real-time Data      |  |
|  | usb_init()  |  | 接口         |  | usb_fetch_real_data |  |
|  +-------------+  +-------------+  +---------------------+  |
+----------------------------+--------------------------------+
                             | Socket通讯
                             v
+-------------------------------------------------------------+
|              Device Manager Server (远端服务)                |
|              (adapter_server: 172.16.4.33:9000)             |
+----------------------------+--------------------------------+
                             | USB协议
                             v
+-------------------------------------------------------------+
|                    Hardware Boards                           |
|  +--------+ +--------+ +--------+ +--------+ +----------+  |
|  | PGB板  | | PPS板  | |SYNC板  | | ASIC板 | |  DIG板   |  |
|  |(FPGA/ | |(FPGA/  | |(FPGA/  | |(FPGA/  | | (DIG)    |  |
|  |  MCU) | |  MCU)  | |  MCU)  | |  MCU)  | |          |  |
|  +--------+ +--------+ +--------+ +--------+ +----------+  |
+-------------------------------------------------------------+
```

## 3. 主要功能模块

### 3.1 初始化流程

```
usb_init(srv_addr)
       |
       v
+--------------------------------------+
| 加载配置文件 config.ini              |
|  * debug                             |
|  * adapter_server (默认172.16.4.33:9000)  |
|  * usb_device_addr_id               |
+------+-------------------------------+
       |
       v
+--------------------------------------+
| 建立与Device Manager服务端的Socket连接|
+------+-------------------------------+
       |
       v
+--------------------------------------+
| 返回: 0成功, 非0失败                 |
+--------------------------------------+
```

### 3.2 OTA升级流程

```
usb_ota_start_upgrade(type, version, device_addr)
       |
       v
+--------------------------------------+
| 向服务端发送升级请求                  |
| type: FPGA/MCU/CAL_FILE 等          |
+------+-------------------------------+
       |
       v
+--------------------------------------+
| 循环查询升级进度                      |
| usb_ota_query_progress()             |
|                                      |
| +--------------------------+         |
| | progress < 1.0: 继续轮询  |         |
| | progress >= 1.0: 升级完成 |         |
| +--------------------------+         |
+------+-------------------------------+
       |
       v
+--------------------------------------+
| usb_ota_complete_upgrade()           |
| 通知服务端升级完成                    |
+--------------------------------------+
```

### 3.3 实时数据获取流程

```
usb_fetch_real_data(device_addr)
       |
       v
+--------------------------------------+
| 向Device Manager服务端发起请求        |
+------+-------------------------------+
       |
       v
+--------------------------------------+
| 返回real_data结构体包含:             |
|  * temperature_ptr (温度)            |
|  * voltage_ptr (电压)                |
|  * current_ptr (电流)                |
|  * board_status (板状态)             |
|  * ad9528/9545时钟锁定状态           |
|  * serdes状态                        |
|  * pwm频率检测                       |
+------+-------------------------------+
       |
       v
+--------------------------------------+
| 用户调用usb_free_real_data()释放内存 |
+--------------------------------------+
```

### 3.4 板卡信息查询API

```
DIG_GetBoardExist(type, slot, &val)    -> 获取板卡在位状态
DIG_GetBoardID(type, slot, id, ...)    -> 获取板卡ID
DIG_GetBoardSN(type, slot, sn, ...)    -> 获取板卡序列号
DIG_GetBoardTemp(type, slot, idx, &t)  -> 获取温度
DIG_GetBoardVol(type, slot, idx, &v)   -> 获取电压
DIG_GetClockChipState(type, slot, ...) -> 获取时钟锁定状态
DIG_GetSerdesState(type, slot, ...)    -> 获取Serdes状态
DIG_GetPwmFrequency(type, slot, ...)   -> 获取PWM频率
```

## 4. 支持的板卡类型

```
+----------------------------------------------+
|              板卡类型 (board_type)            |
+-------------+--------------------------------+
| CP系列      | FT系列                         |
+-------------+--------------------------------+
| CP_SYNC(0x11) | FT_SYNC(0x21)               |
| CP_PGB (0x12) | FT_PGB (0x22)               |
| CP_DPS (0x13) | FT_PPS (0x23)               |
| CP_PEM (0x14) |                              |
| CP_RCA (0x15) |                              |
| CP_DIG (0x1B) | FT_DIG (0x2B)               |
+-------------+--------------------------------+
| ASIC (0x20)                                 |
| TH_MONITOR(0x40)  MF_MONITOR(0x4F)          |
+----------------------------------------------+
```

## 5. OTA升级类型

```
+----------------------------------------------------------+
|                     OTA 升级类型                          |
+----------------+-----------------------------------------+
| 板卡类型       | 支持的OTA类型                            |
+----------------+-----------------------------------------+
| PGB板          | FPGA主/从, MCU                          |
| PPS板          | FPGA主/从, MCU                          |
| SYNC板         | FPGA, MCU                               |
| ASIC板         | FPGA主/从, MCU                          |
| CPDIG/CPDPS等  | FPGA, MCU                               |
| 校准文件       | CAL_FILE, MV_CAL, MI_CAL, FV_CAL等      |
+----------------+-----------------------------------------+
```

## 6. 关键文件说明

| 文件 | 说明 |
|------|------|
| main.cpp | 测试程序入口，包含各种测试函数 |
| libusb/lib_interface.h | 外部提供的API接口定义 |
| libusb/xbasicmgr.hpp | 基础管理器(发布-订阅模式) |
| libusb/mgr_network.h | 网络通信管理 |
| libusb/mgr_session.h | 会话管理 |
| config/config.ini | 配置文件 |

## 7. 使用示例

```bash
# OTA升级
otaupgrade SYNC_MCU 0.0.0.1

# 读取实时数据3次
read_real 3

# 读取校准文件
read_cal
```

## 8. 编译构建

```bash
./build.sh
```

编译后会生成可执行文件，可用于测试各种USB设备管理功能。
